# Burl

A clean, lightweight Git GUI for Windows, built with C# and WPF.

Like the wood it's named after, Burl turns a tangled history into something beautiful.

## Stack

- .NET 10 / WPF
- LibGit2Sharp
- Git CLI for push and pull

## Build

```
dotnet build
dotnet run --project Burl
```
